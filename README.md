# Mi Pedido MaLu

**Sistema de gestión de pedidos para Restaurante-Bar MaLu**

## 📌 Descripción del proyecto

**Mi Pedido MaLu** es un proyecto de software orientado a mejorar la gestión y el seguimiento de los pedidos dentro de Restaurante-Bar MaLu. Su propósito es facilitar la coordinación entre el personal de servicio, la cocina y la administración mediante una solución organizada, intuitiva y adaptada a las necesidades del restaurante.

Este repositorio centraliza la documentación, los requisitos, el diseño, las decisiones de arquitectura, las pruebas de calidad y los recursos relacionados con el desarrollo y mantenimiento del sistema.

## 🎯 Objetivos

- Organizar y mejorar el proceso de gestión de pedidos.
- Facilitar la comunicación y coordinación entre las áreas involucradas.
- Documentar los requisitos y el funcionamiento esperado del sistema.
- Mantener un registro de las decisiones de diseño y arquitectura.
- Verificar la calidad del software mediante pruebas y documentación.
- Centralizar los recursos necesarios para el desarrollo y mantenimiento del proyecto.

## 🧩 Organización del sistema

El proyecto contempla las necesidades de las distintas áreas involucradas en la gestión de pedidos:

- **Servicio:** gestión y registro de pedidos.
- **Cocina:** consulta y seguimiento de los pedidos recibidos.
- **Administración:** supervisión y gestión de la información correspondiente.

Los permisos y las funcionalidades específicas de cada perfil se definirán en la documentación de requisitos y de usuarios.

## 🧪 Calidad del software

La calidad del sistema se documentará mediante actividades de verificación y validación, incluyendo:

- Revisión de requisitos.
- Diseño y ejecución de casos de prueba.
- Registro y seguimiento de errores.
- Comprobación de las funcionalidades implementadas.
- Documentación de resultados y oportunidades de mejora.

Consulta la sección **Pruebas de Calidad** para acceder a los recursos correspondientes.
